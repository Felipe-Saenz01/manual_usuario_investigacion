<Card title="Objetivo Funcional" icon="open-book">
    El módulo de **Proyectos de Investigación** es el núcleo del sistema, permitiendo 
    crear y gestionar proyectos desde su formulación hasta su finalización. Incluye 
    la definición del problema, metodología, participantes, actividades programadas 
    y productos esperados.

## Acceso y navegación

Para acceder a este módulo, sigue la siguiente ruta:

**Menú Principal → Investigación → Proyectos**

{/* ![Vista inicial de Proyectos](@assets/guias/proyectos/vista_inicial_proyectos.png) */}

---

## Estados del proyecto

Un proyecto puede encontrarse en los siguientes estados:

| Estado | Descripción | Acciones permitidas |
|--------|-------------|---------------------|
| **En Formulación** | El proyecto está siendo creado o editado, campos pueden estar incompletos | Editar todos los campos, agregar participantes |
| **Formulado** | Proyecto completo con todos los campos requeridos diligenciados | Gestionar actividades y productos, editar información |

## Funcionalidades principales

### 1. Listado de Proyectos

La vista principal muestra todos los proyectos según tu rol:

- **Investigador:** Proyectos donde participa
- **Coordinador:** Proyectos de su grupo de investigación
- **Administrador:** Todos los proyectos del sistema

| Campo | Descripción |
|-------|-------------|
| **Título** | Nombre del proyecto |
| **Eje Temático** | Línea de investigación |
| **Estado** | Estado actual del proyecto |
| **Grupos** | Grupos de investigación vinculados |
| **Participantes** | Número de investigadores |
| **Acciones** | Ver, editar, enviar a revisión |

### 2. Crear un Nuevo Proyecto

<Steps>
1. **Iniciar creación**
    
    Presiona el botón **`+ Nuevo Proyecto`** en la parte superior.

    {/* ![Botón nuevo proyecto](@assets/guias/proyectos/boton_nuevo_proyecto.png) */}

2. **Seleccionar tipo de proyecto**
    
    Elige el tipo de proyecto:
    - **Formulado:** Proyecto completo con todos los campos requeridos
    - **En Formulación:** Proyecto en proceso, campos pueden estar incompletos

    <Aside type="note" title="Proyectos en Formulación">
    Si seleccionas "En Formulación", el sistema creará automáticamente 
    un producto "Formulación del Proyecto" asociado al proyecto.
    </Aside>

3. **Información básica**
    
    Completa los campos iniciales:
    - **Título:** Nombre descriptivo del proyecto (requerido)
    - **Eje Temático:** Selecciona la línea de investigación (requerido)

    {/* ![Formulario información básica](@assets/guias/proyectos/formulario_info_basica.png) */}

4. **Campos de formulación (solo para proyectos Formulados)**
    
    Si seleccionaste "Formulado", completa todos los campos requeridos:
    - **Resumen ejecutivo:** Resumen conciso del proyecto
    - **Planteamiento del problema:** Situación problemática identificada
    - **Antecedentes:** Trabajos previos relacionados
    - **Justificación:** Importancia y pertinencia del proyecto
    - **Objetivos:** Objetivo general y específicos
    - **Metodología:** Enfoque metodológico
    - **Resultados:** Productos y resultados esperados
    - **Riesgos:** Riesgos y estrategias de mitigación
    - **Bibliografía:** Referencias bibliográficas

    <Aside type="tip" title="Campos opcionales en Formulación">
    Si el proyecto está "En Formulación", estos campos son opcionales y 
    se llenarán automáticamente con "En Formulación" si no se completan.
    </Aside>

5. **Seleccionar participantes**
    
    Agrega los investigadores que participarán en el proyecto:
    - Selecciona uno o más investigadores de la lista
    - El usuario logueado se agrega automáticamente

6. **Guardar proyecto**
    
    Presiona **`Guardar`** para crear el proyecto. El sistema asociará 
    automáticamente el proyecto al grupo de investigación del usuario.

</Steps>

### 3. Gestionar Participantes

Los participantes se gestionan durante la creación o edición del proyecto:

<Steps>
1. **Seleccionar participantes**
    
    En el formulario de creación/edición, selecciona los investigadores 
    que participarán en el proyecto desde el campo **"Usuarios"**.

    <Aside type="note" title="Investigadores disponibles">
    Solo se muestran investigadores con tipo "Investigador" o "Lider Grupo".
    Puedes agregar investigadores de cualquier grupo de investigación.
    </Aside>

2. **Confirmar selección**
    
    Los participantes seleccionados se asociarán automáticamente al proyecto 
    al guardar.
</Steps>

<Aside type="note" title="Vinculación automática de grupos">
El proyecto se vincula automáticamente al grupo de investigación del usuario 
que lo crea. Si el usuario pertenece a un grupo, el proyecto quedará asociado 
a ese grupo.
</Aside>

### 5. Definir Actividades del Proyecto

<Steps>
1. **Acceder a actividades**
    
    En el proyecto, navega a la pestaña **"Actividades"**.

2. **Crear actividad**
    
    Presiona **`+ Nueva Actividad`** y completa:
    - **Nombre:** Descripción de la actividad
    - **Responsable:** Investigador a cargo
    - **Fecha inicio:** Fecha de inicio programada
    - **Fecha fin:** Fecha de finalización esperada

    {/* ![Formulario actividad](@assets/guias/proyectos/formulario_actividad.png) */}

3. **Guardar actividad**
    
    Presiona **`Guardar`** para registrar la actividad.

</Steps>

### 6. Editar un Proyecto

<Steps>
1. **Acceder a edición**
    
    Solo el autor del proyecto (primer usuario asociado) puede editarlo. 
    Presiona el botón de **edición** (ícono de lápiz).

2. **Verificar permisos**
    
    El sistema verifica que tengas el permiso `editar-proyecto` y que seas 
    el autor del proyecto.

3. **Modificar información**
    
    Actualiza los campos necesarios. Si el proyecto estaba "En Formulación", 
    puedes completar todos los campos para convertirlo en "Formulado".

4. **Guardar cambios**
    
    Presiona **`Actualizar`** para guardar los cambios.
</Steps>

<Aside type="caution" title="Restricciones de edición">
- Solo el autor del proyecto puede editarlo
- Se requiere el permiso `editar-proyecto`
- No se puede cambiar el proyecto asociado de los productos una vez creados
</Aside>

## Reglas de negocio

<CardGrid>
  <Card title="Mínimo un participante" icon="warning">
    Todo proyecto debe tener al menos un investigador participante.
  </Card>
  <Card title="Vinculación automática" icon="information">
    El proyecto se vincula automáticamente al grupo de investigación del usuario creador.
  </Card>
  <Card title="Campos según tipo" icon="warning">
    Los campos de formulación son requeridos solo para proyectos "Formulados".
  </Card>
  <Card title="Edición restringida" icon="information">
    Solo el autor del proyecto puede editarlo, y requiere el permiso `editar-proyecto`.
  </Card>
  <Card title="Eliminación condicional" icon="warning">
    No se puede eliminar un proyecto que tenga productos investigativos asociados.
  </Card>
</CardGrid>

## Errores comunes y soluciones

| Error | Causa | Solución |
|-------|-------|----------|
| "Campos incompletos" | Faltan campos obligatorios | Completa todos los campos marcados con (*) |
| "Sin participantes" | El proyecto no tiene investigadores | Agrega al menos un participante |
| "Sin grupos vinculados" | No hay grupos asociados | Vincula al menos un grupo de investigación |
| "No puede editar" | El proyecto está en revisión | Espera el concepto del coordinador |

## Preguntas frecuentes

<Aside type="tip" title="¿Puedo eliminar un proyecto?">
Solo puedes eliminar proyectos si eres el autor, tienes el permiso 
`eliminar-proyecto` y el proyecto no tiene productos investigativos asociados.
</Aside>

<Aside type="tip" title="¿Cómo agrego productos al proyecto?">
Los productos se gestionan desde el módulo de **Productos Investigativos** 
y se vinculan al proyecto durante su creación.
</Aside>

<Aside type="tip" title="¿Qué pasa si rechazan mi proyecto?">
Puedes crear un nuevo proyecto corrigiendo las observaciones. El proyecto 
rechazado quedará en el historial como referencia.
</Aside>
