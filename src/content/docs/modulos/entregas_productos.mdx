<Card title="Objetivo Funcional" icon="open-book">
    El módulo de **Entregas de Productos** permite a los investigadores registrar 
    el avance de sus productos investigativos mediante dos tipos de entregas: 
    **Planeación** (proyección del trabajo a realizar) y **Evidencia** (demostración 
    del trabajo completado). El sistema incluye funcionalidades de comparación para 
    detectar similitudes entre entregas.
</Card>

## Acceso y navegación

Para acceder a este módulo, sigue la siguiente ruta:

**Menú Principal → Investigación → Entregas**

También puedes acceder desde un producto específico:

**Productos → [Producto] → Pestaña "Entregas" → `+ Nueva Entrega`**

{/* ![Vista inicial de Entregas](@assets/guias/entregas/vista_inicial_entregas.png) */}

## Tipos de entrega

El sistema maneja dos tipos de entregas por período académico:

<CardGrid>
  <Card title="Planeación" icon="pencil">
    **¿Qué es?** Documento que describe el trabajo proyectado para el período.
    
    **¿Cuándo se entrega?** Al inicio del período, antes de la fecha límite de planeación.
    
    **Contenido:** Objetivos del período, actividades programadas, horas estimadas.
  </Card>
  <Card title="Evidencia" icon="document">
    **¿Qué es?** Documento que demuestra el trabajo realizado durante el período.
    
    **¿Cuándo se entrega?** Al final del período, antes de la fecha límite de evidencias.
    
    **Contenido:** Secciones del producto desarrolladas, archivos de soporte.
  </Card>
</CardGrid>

---

## Flujo de trabajo

```
1. Planeación (inicio del período)
   ↓
2. Desarrollo del trabajo
   ↓
3. Evidencia (final del período)
   ↓
4. Revisión por coordinador
   ↓
5. Aprobación o Corrección
```

## Estados de una entrega

| Estado | Descripción | Color |
|--------|-------------|-------|
| **Pendiente** | Entrega creada, sin enviar a revisión | 🟡 Amarillo |
| **En revisión** | Enviada y esperando evaluación | 🔵 Azul |
| **Corrección** | Requiere ajustes según observaciones | 🟠 Naranja |
| **Aprobado** | Entrega aceptada por el coordinador | 🟢 Verde |
| **Rechazado** | Entrega no aceptada | 🔴 Rojo |

## Funcionalidades principales

### 1. Listado de Entregas

La vista principal muestra las entregas organizadas por período:

| Campo | Descripción |
|-------|-------------|
| **Producto** | Producto investigativo asociado |
| **Tipo** | Planeación o Evidencia |
| **Período** | Período académico |
| **Progreso** | Porcentaje de avance reportado |
| **Estado** | Estado actual de la entrega |
| **Acciones** | Ver, editar, enviar a revisión |

### 2. Crear una Planeación

<Steps>
1. **Verificar período activo**
    
    Asegúrate de que el período académico esté activo y dentro del plazo 
    de planeación.

    <Aside type="note" title="Fechas límite">
    Puedes ver las fechas límite en **Períodos** o en la parte superior 
    del módulo de entregas.
    </Aside>

2. **Iniciar creación**
    
    Presiona **`+ Nueva Entrega`** y selecciona tipo **"Planeación"**.

    {/* ![Crear planeación](@assets/guias/entregas/crear_planeacion.png) */}

3. **Seleccionar producto**
    
    Elige el producto investigativo para el cual registrarás la planeación.

4. **Registrar planeación**
    
    Completa la información de planeación:
    - **Planeación:** Describe las actividades y objetivos para el período (formato JSON)
    - **Progreso planeado:** Porcentaje de avance que esperas alcanzar (0-100%)

    {/* ![Formulario planeación](@assets/guias/entregas/formulario_planeacion.png) */}

    <Aside type="note" title="Formato de planeación">
    La planeación se almacena en formato JSON y puede incluir:
    - Objetivos específicos
    - Actividades programadas
    - Entregables esperados
    - Cronograma de trabajo
    </Aside>

5. **Guardar planeación**
    
    Presiona **`Guardar`** para almacenar la planeación. Podrás editarla 
    hasta enviarla a revisión.

</Steps>

### 3. Crear una Evidencia

<Steps>
1. **Verificar existencia de planeación**
    
    Para crear una evidencia, debe existir una planeación aprobada 
    para el mismo producto y período.

    <Aside type="danger" title="Requisito previo">
    No podrás crear evidencias si no tienes una planeación aprobada 
    para el período actual.
    </Aside>

2. **Iniciar creación**
    
    Presiona **`+ Nueva Entrega`** y selecciona tipo **"Evidencia"**.

3. **Seleccionar producto**
    
    El sistema mostrará solo los productos con planeación aprobada.

4. **Adjuntar archivo de evidencia**
    
    Carga el documento PDF que contiene la evidencia del trabajo realizado:
    - Presiona **`Seleccionar archivo`**
    - Elige el archivo PDF desde tu computador
    - Formatos permitidos: PDF

    <Aside type="note" title="Extracción automática">
    El sistema extraerá automáticamente las secciones del PDF cuando se 
    use en el módulo de Revisión Inteligente. Asegúrate de que el PDF 
    tenga texto seleccionable.
    </Aside>

5. **Indicar progreso alcanzado**
    
    Registra el porcentaje de avance real alcanzado durante el período (0-100%).

6. **Guardar evidencia**
    
    Presiona **`Guardar`** para almacenar la evidencia. Podrás editarla 
    hasta enviarla a revisión.

</Steps>

### 4. Enviar a Revisión

Una vez completada la entrega:

<Steps>
1. Abre la entrega (planeación o evidencia)
2. Verifica que toda la información esté completa
3. Presiona el botón **`Enviar a Revisión`**
4. Confirma la acción en el diálogo emergente
5. La entrega cambiará a estado "En revisión"
</Steps>

<Aside type="caution" title="Acción irreversible">
Una vez enviada a revisión, no podrás editar la entrega hasta que 
el coordinador emita su concepto.
</Aside>

### 5. Proceso de Revisión (Coordinadores)

<Tabs>
  <TabItem label="Aprobar Entrega">
    1. Accede a **Revisiones Pendientes**
    2. Selecciona la entrega a revisar
    3. Revisa el contenido y las secciones
    4. Presiona **`Aprobar`**
    5. Agrega comentarios de retroalimentación (opcional)
    6. Confirma la aprobación
    
    El progreso del producto se actualizará automáticamente.
  </TabItem>
  <TabItem label="Solicitar Corrección">
    1. Identifica los aspectos a mejorar
    2. Presiona **`Solicitar Corrección`**
    3. Detalla las observaciones específicas
    4. Confirma el envío
    
    El investigador recibirá notificación para realizar ajustes.
  </TabItem>
  <TabItem label="Rechazar">
    1. Documenta las razones del rechazo
    2. Presiona **`Rechazar`**
    3. Ingresa justificación detallada
    4. Confirma el rechazo
  </TabItem>
</Tabs>

## Relación con Revisión Inteligente

Las evidencias entregadas pueden ser comparadas usando el módulo de 
**Revisión Inteligente**:

- Las evidencias se extraen automáticamente del PDF
- Se dividen en secciones para análisis detallado
- Se comparan con otras evidencias del mismo producto
- Se calcula similitud usando IA (OpenAI)

Para más información sobre el proceso de comparación, consulta el módulo 
de **Revisión Inteligente**.

## Reglas de negocio

<CardGrid>
  <Card title="Una entrega por tipo/período" icon="warning">
    Solo puedes tener una planeación y una evidencia por producto 
    en cada período académico.
  </Card>
  <Card title="Planeación opcional" icon="information">
    La planeación no es estrictamente obligatoria, pero se recomienda 
    para mejor seguimiento del avance.
  </Card>
  <Card title="Fechas límite" icon="warning">
    Las entregas deben realizarse antes de las fechas límite del período 
    (fecha límite de planeación y fecha límite de evidencias).
  </Card>
  <Card title="PDF requerido para evidencia" icon="information">
    La evidencia debe incluir un archivo PDF que será procesado 
    automáticamente para extracción de secciones.
  </Card>
</CardGrid>

## Errores comunes y soluciones

| Error | Causa | Solución |
|-------|-------|----------|
| "Fuera del plazo" | La fecha límite ha pasado | Contacta al coordinador para solicitar extensión |
| "Producto no encontrado" | El producto fue eliminado o no tienes acceso | Verifica que el producto exista y tengas permisos |
| "Período no válido" | El período no está activo o no existe | Selecciona un período académico válido |
| "Archivo requerido" | La evidencia debe incluir un archivo PDF | Adjunta el archivo PDF de la evidencia |
| "Progreso inválido" | El porcentaje está fuera del rango 0-100 | Ingresa un valor válido entre 0 y 100 |

## Preguntas frecuentes

<Aside type="tip" title="¿Puedo modificar una entrega aprobada?">
No, las entregas aprobadas quedan bloqueadas. Si necesitas hacer cambios, 
deberás esperar al siguiente período o contactar al administrador.
</Aside>

<Aside type="tip" title="¿Qué pasa si no entrego a tiempo?">
Si no entregas dentro del plazo, deberás solicitar una extensión al 
coordinador. Las entregas fuera de plazo pueden afectar la evaluación 
del período.
</Aside>

<Aside type="tip" title="¿Qué formato debe tener el PDF de evidencia?">
El PDF debe tener texto seleccionable (no solo imágenes escaneadas). 
Si tienes un PDF escaneado, usa herramientas OCR antes de subirlo.
</Aside>

<Aside type="tip" title="¿Puedo actualizar una entrega después de guardarla?">
Sí, puedes editar la entrega hasta que la envíes a revisión. Una vez 
enviada, solo el coordinador puede cambiar su estado.
</Aside>
